# Clock Android App
Application ID: com.aistudio.clock.qxvrtm

Features:
- 24-hour HH:MM:SS
- Dark charcoal UI
- White hours/seconds and orange minutes
- Home-screen clock widget
- Tap widget to open app
- Boot/time/timezone/date/locale handling

Build:
./gradlew :app:assembleDebug

APK:
app/build/outputs/apk/debug/app-debug.apk
